# Enterprise Infrastructure Automation & DevOps Lab

A hands-on infrastructure engineering project focused on enterprise networking, network automation, cloud infrastructure, and DevOps practices.

## Project Objectives

- Design and simulate a multi-site enterprise network.
- Implement routing protocols such as OSPF.
- Automate network configuration using Python and Ansible.
- Provision cloud infrastructure using Terraform and Microsoft Azure.
- Build CI/CD pipelines with GitHub Actions.
- Deploy containerized applications using Docker and Kubernetes.
- Implement monitoring and observability.

## Technology Stack

Linux | Docker | Containerlab | FRRouting | Python | Ansible | Git | GitHub Actions | Terraform | Azure | Kubernetes | Prometheus | Grafana

## Project Phases

1. Network Infrastructure and Automation
2. Azure Infrastructure as Code
3. Docker and Kubernetes
4. CI/CD Automation
5. Monitoring and Observability
